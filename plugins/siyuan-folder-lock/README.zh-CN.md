# 安全锁

安全锁是一个为单篇思源文档及其当前子文档树提供密码保护的插件。插件会用随机 AES-256-GCM 数据密钥加密每篇文档的快照，再分别用密码派生密钥和恢复码派生密钥保护数据密钥，最后将可见文档替换为锁定提示。

## 功能范围

- 加锁所选文档，以及加锁时发现的全部子文档。
- 支持使用密码或仅在首次加锁时显示的恢复码解锁。
- 密码或恢复码解锁期间使用不透明隐私遮罩，避免背景中的笔记正文透过对话框显示。
- 加锁或重新上锁写入锁定提示后，会刷新仍打开的受保护编辑器，避免页签继续显示旧明文。
- 只有在恢复全部受保护文档，并重新使用密码或恢复码验证后，才会永久移除安全锁。
- 相关编辑页签打开期间保持解锁，最后一个页签关闭后重新上锁；正常退出思源时会等待最新密文持久化完成。通过右键菜单解锁但未打开页签时，会在 30 秒后重新上锁。
- 每次加锁和重新上锁都会新增一代不可变加密快照；快照落盘、读回并完整解密比对成功后，才允许替换可见正文。
- 新版快照直接保存完整 `.sy` 原始结构，不经过 Markdown 或 BlockDOM 转换，因此表格、属性视图引用、块属性和块 ID 都按原结构恢复。
- 原始结构写回后会逐字段重新读取并比对；任一文档不一致时立即停止，并将本批已写入文档按原始结构回滚。
- 解锁只读取密文并恢复正文，绝不覆盖现有快照；最新快照损坏时会按新到旧尝试历史快照。
- 锁清单先提交并验证一个持久化槽，再将同一代清单镜像到第二个槽；任一有效副本都能恢复最新已提交的锁元数据。
- 若异常退出留下了比加密快照更新的明文，下次解锁会保留该明文，不会使用旧快照覆盖。
- 检测到锁定占位内容时拒绝生成新快照，避免把占位文案当成正文提交。
- 禁止父子目录范围互相重叠的锁。

## 使用方法

1. 先备份或创建思源工作空间快照，并确认备份可以正常打开。
2. 在文档树中右键单击文档，选择「加安全锁」。
3. 输入并确认任意长度的非空密码。短密码更容易被猜中，建议在方便的情况下使用较强密码。
4. 将恢复码复制到思源工作空间之外的安全位置，核对副本后确认已经保存。
5. 解锁时打开文档或使用右键菜单，然后输入密码，或者选择使用恢复码解锁。
6. 关闭所有相关编辑页签以触发重新上锁，并在退出思源前确认文档已经恢复锁定提示。
7. 若要停止保护，请右键单击加锁根文档，选择「移除安全锁」，完成验证并检查恢复后的文档。

## 恢复码与备份

插件不会保存密码或恢复码。如果两者同时丢失，通常无法恢复加密快照。请将恢复码离线保存或存入可信的密码管理器，切勿只保存在同一个被锁定的思源工作空间内。请备份并验证完整工作空间，其中必须包含 `data/storage/petal/siyuan-folder-lock/`，因为该目录中的 `locks-v2-a`、`locks-v2-b` 和 `snapshots/` 保存恢复所需的双槽清单、历史加密快照和受保护的数据密钥。

停用或卸载插件前，必须对每个加锁根文档执行「移除安全锁」，逐篇验证文档内容，再创建一份新备份。仍有文档显示锁定提示时不要卸载插件。插件卸载和应用退出时只能尽力重新上锁；若进程被强制终止，无法保证操作完成。

为了防止误操作破坏最后的恢复版本，历史加密快照不会自动删除。「移除安全锁」会恢复正文并停止保护，但保留不可变加密快照。只有在确认不存在任何加锁文档、完成工作空间备份且确实不再需要恢复旧版本后，才能关闭思源并手动清理该插件存储目录。

## 安全设计与隐私说明

- 文档快照使用 AES-256-GCM，每次加密生成新的 96 位 IV，并通过附加认证数据绑定文档 ID。
- 密码和恢复码使用 PBKDF2-HMAC-SHA-256、随机 128 位盐和 600,000 次迭代派生密钥。
- 每代快照使用随机标识并只写入一次；写入后从磁盘读回，逐篇完成认证解密和原文比对。
- 双槽清单带单调递增序号，正常情况下保存相同的最新一代；启动时只采用序号最高的有效清单，两槽均损坏时插件停止运行，不会静默重置为空状态。
- 重新上锁会追加新快照并保留所有旧引用；解锁过程不会写入或刷新密文。
- 恢复码包含 100 位随机性，仅在首次加锁时显示。复制恢复码会将其写入操作系统剪贴板；妥善保存后请清空剪贴板。
- 密码与恢复码只在对话框和相关操作需要时存在于应用内存；目录解锁期间，已解包的文档密钥会保留在内存中。
- 加密快照和受保护密钥保存在思源工作空间的插件存储中，并遵循该工作空间的备份与同步行为。
- 插件不会向第三方服务发送文档内容、密码、恢复码或遥测数据。

## 已知限制

本插件提供的是应用层访问屏障，不是全盘加密工具，也不能安全擦除数据。明文可能仍存在于思源历史记录、搜索索引、数据库页、操作系统缓存、备份、同步副本、导出文件、截图，以及加锁前或解锁期间产生的其他副本中。能够控制正在运行的思源进程、工作空间文件、插件代码、浏览器开发者工具或操作系统的人，可能在目录解锁时读取明文。

受保护文档集合是一个快照。目录锁定期间新增或移入的文档不会自动受保护。受保护文档在锁定期间被移出原目录树时，下次解锁仍会按文档 ID 恢复；若受保护文档已删除或暂时不可用，解锁会停止，不会丢弃其恢复引用。目录解锁期间移出的文档会在重新上锁后离开保护范围。结构调整后请重新核对文档树。并发编辑、同步冲突、强制退出、存储空间不足、内核错误或第三方插件都可能中断重新上锁。插件会在替换可见内容前保存并验证新一代加密恢复数据；解锁时若发现非占位正文，会优先保留当前磁盘内容；批量写入部分失败时会按原始结构回滚，但仍必须保留经过验证的工作空间备份。

本插件的密码学设计未经过独立安全审计，不宣称零知识、绝对安全或保证恢复。

## 兼容性

- 思源笔记 3.7.1 或更高版本，并包含安全锁所需的原始文档读写接口
- 桌面端、独立桌面窗口和桌面浏览器前端
- Windows、macOS、Linux，以及能够提供受支持桌面前端和 Web Crypto API 的其他后端
